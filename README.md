### โรงเรียนหาดใหญ่วิทยาลัย (ญ.ว.) | ภาคเรียนที่ 2 ปีการศึกษา 2569

ระบบเว็บแอปพลิเคชันบริการข้อมูลวิชาการดิจิทัล สำหรับแสดงตารางเรียน ตารางสอน และตารางการใช้ห้องเรียน/ห้องปฏิบัติการของโรงเรียนหาดใหญ่วิทยาลัย ประจำภาคเรียนที่ 2 ปีการศึกษา 2569 พร้อมระบบรับแจ้งและติดตามปัญหาตารางเรียนตารางสอนสำหรับนักเรียน ครู บุคลากร และระบบจัดการสำหรับฝ่ายบริหารวิชาการ

## 🌟 ฟังก์ชันหลักของระบบ (Key Features)

### 1. ตารางเรียนนักเรียน (Student Timetables) - **แยกรายห้องเดี่ยว (Single-Room Only)**
- ครอบคลุม **102 ห้องเรียน** ทุกระดับชั้น (ม.1 ถึง ม.6)
  - ม.1 (14 ห้อง: ม.1/1 - ม.1/14)
  - ม.2 (14 ห้อง: ม.2/1 - ม.2/14)
  - ม.3 (14 ห้อง: ม.3/1 - ม.3/14)
  - ม.4 (20 ห้อง: ม.4/1 - ม.4/20)
  - ม.5 (20 ห้อง: ม.5/1 - ม.5/20)
  - ม.6 (20 ห้อง: ม.6/1 - ม.6/20)
- **ระบบตัดแยกตารางเรียนรายห้องเฉพาะห้องนั้น ๆ (Standalone Single-Class PDF)**:
  - แสดงเฉพาะตารางเรียนของห้องที่เลือกเท่านั้น (เอกสารขนาด 1 หน้า)
  - ไม่แสดงตารางของห้องอื่นที่อยู่ในหน้าเดียวกัน และไม่ต้องโหลดทั้งไฟล์
  - สะดวกต่อการดู พิมพ์ และดาวน์โหลดไปใช้งานเฉพาะห้องเรียน
  - สามารถสลับดูไฟล์รวมทั้งระดับชั้นได้หากต้องการ
- แยกตามแผนการเรียน: **English Program (EP)**, **SMA**, **SMTE / SMT**, **EIS** และ **ห้องเรียนทั่วไป**
- แสดงห้องเรียนประจำ จำนวนคาบเรียนต่อสัปดาห์
- ระบบค้นหาด่วนตามชื่อห้องเรียน และตัวกรองระดับชั้น
- หน้าต่างแสดงตารางเรียน PDF ความละเอียดสูง พร้อมปุ่มพิมพ์ ดาวน์โหลด และเปิดแท็บใหม่
- ปุ่มลัด **"แจ้งปัญหาตารางเรียนของห้องนี้"** (ระบบกรอกข้อมูลห้องเรียนให้อัตโนมัติ)

### 2. ตารางสอนครู (Teacher Timetables) - **แยกรายบุคคล (Single-Teacher Only)**
- ครอบคลุมครูผู้สอนและอาจารย์ชาวต่างชาติ **210 ท่าน** ทุกกลุ่มสาระการเรียนรู้
- **ระบบตัดแยกตารางสอนรายบุคคล (Standalone Single-Teacher PDF)**:
  - แสดงเฉพาะตารางสอนเดี่ยว 1 หน้าของครูท่านนั้น ๆ ไม่แสดงครูท่านอื่นที่เคยอยู่ในหน้าเดียวกัน
  - สะดวกต่อการดู พิมพ์ และดาวน์โหลดตารางสอนรายบุคคล
  - มีปุ่มสลับไปดูไฟล์รวมกลุ่มสาระฯ ได้ตลอดเวลา
- แสดงรหัสครูผู้สอน (เช่น `#201`, `#202`), กลุ่มสาระฯ, ภาระการสอน (จำนวนคาบต่อสัปดาห์)
- ค้นหาได้ด้วยชื่อ-สกุล หรือรหัสครูผู้สอน

### 3. ตารางการใช้ห้อง (Room Utilization Schedules) - **แยกรายห้องเดี่ยว (Single-Room Only)**
- ครอบคลุม **138 ห้องเรียน ห้องปฏิบัติการ และสนามกีฬา** ทุกอาคาร
- **ระบบตัดแยกตารางการใช้ห้องเดี่ยว (Standalone Single-Room PDF)**:
  - แสดงเฉพาะตารางการใช้ห้อง 1 หน้าของห้องนั้น ๆ ไม่ต้องเปิดทั้งเล่มอาคาร
  - สะดวกต่อการพิมพ์ติดหน้าห้องเรียน หรือนำไปใช้วางแผนการเรียนการสอน
  - มีปุ่มสลับไปดูไฟล์รวมทั้งอาคารได้
- แสดงรายละเอียดการใช้งานห้อง วัตถุประสงค์ (เช่น ห้องปฏิบัติการ, วิชาวิทยาศาสตร์, สุขศึกษา ฯลฯ)
- ค้นหาได้ทั้งหมายเลขห้องและชื่ออาคาร

### 4. ระบบรับแจ้งปัญหาเกี่ยวกับตารางเรียน ตารางสอน (Issue Reporting System)
- แบบฟอร์มออนไลน์สำหรับนักเรียน ครู ผู้ปกครอง และบุคลากร
- รองรับประเภทปัญหา:
  1. คาบเรียนซ้ำซ้อน / คาบชนกัน (สองวิชาตรงกัน)
  2. ข้อมูลห้องเรียนไม่ตรง / สลับห้อง / ชนกับผู้อื่น
  3. ข้อมูลครูผู้สอนไม่ถูกต้อง / ผิดท่าน
  4. รหัสวิชา / ชื่อวิชา / หน่วยกิต ไม่ถูกต้อง
  5. คาบเรียนตกหล่น / ขาดครูผู้สอน
  6. ปัญหาการใช้ห้อง / อุปกรณ์ประจำห้อง
  7. ปัญหาอื่นๆ
- ระบุระดับความเร่งด่วน (ปกติ, เร่งด่วน, ด่วนที่สุด)
- ระบบ Autocomplete เชื่อมโยงรายชื่อห้องเรียน ครู และห้อง เพื่อความแม่นยำในการระบุเป้าหมาย
- ออกหมายเลขคำร้องอัตโนมัติ (Ticket ID: `YW69-XXXX`) พร้อมปุ่มคัดลอก

### 5. ระบบตรวจสอบและติดตามสถานะเรื่องแจ้ง (Issue Tracking)
- ค้นหาความคืบหน้าได้ทันทีด้วย **Ticket ID** หรือ **เบอร์โทรศัพท์**
- แสดง Timeline ความคืบหน้า 3 ขั้นตอน:
  - ขั้นที่ 1: รับเรื่องในระบบ
  - ขั้นที่ 2: ตรวจสอบและประสานงาน
  - ขั้นที่ 3: ดำเนินการแก้ไขเสร็จสิ้น
- แสดงคำชี้แจงและบันทึกผลการแก้ไขจากงานจัดตารางเรียน

### 6. ระบบจัดการสำหรับงานจัดตารางเรียน (Timetable Management Portal - เจ้าหน้าที่เท่านั้น)
- **แยกส่วนการเข้าถึงออกจากผู้ใช้ทั่วไปอย่างปลอดภัย**:
  - ผู้เข้าใช้งานต้องยืนยันตัวตนด้วย **Username & Password**
  - มีระบบเซสชันโทเคน (Authentication Token) ปกป้อง API ในการอัปเดตและจัดการตาราง
  - บัญชีเริ่มต้นสำหรับเจ้าหน้าที่:
    - **ชื่อผู้ใช้งาน (Username)**: `admin` | **รหัสผ่าน**: `admin2569` (ตำแหน่ง: หัวหน้างานจัดตารางเรียน)
    - **ชื่อผู้ใช้งาน (Username)**: `schedule` | **รหัสผ่าน**: `yw69schedule` (ตำแหน่ง: เจ้าหน้าที่งานจัดตารางเรียน)
- แดชบอร์ดสรุปสถิติเรื่องแจ้งปัญหาทั้งหมด (Total, Pending, In-Progress, Resolved)
- ตารางบริหารจัดการเรื่องแจ้ง พร้อมตัวกรองสถานะและความเร่งด่วน
- ระบบอัปเดตสถานะการดำเนินงาน พร้อมช่องกรอกคำชี้แจง/บันทึกผลการตรวจสอบถึงผู้แจ้ง
- ระบบส่งออกข้อมูลรายงานเรื่องแจ้งปัญหาในรูปแบบไฟล์ JSON
- ระบบออกจากระบบ (Logout) เพื่อความปลอดภัยของข้อมูลวิชาการ

## 🚀 การเริ่มต้นใช้งาน (Getting Started)

### 1. เข้าใช้งานผ่านเว็บเบราว์เซอร์
เซิร์ฟเวอร์เปิดให้บริการอยู่ที่:
👉 **[http://localhost:3000](http://localhost:3000)**

### 2. คำสั่งสำหรับรันระบบ (Commands)
```bash
# ติดตั้ง dependencies (ดำเนินการไว้เรียบร้อยแล้ว)
npm install

# รันเซิร์ฟเวอร์
npm start

# รันอัปเดตแคตตาล็อกข้อมูลตารางใหม่จากไฟล์ PDF
npm run build:data
```
